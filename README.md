# Experimentation & Pricing Optimization Analytics Platform

## Overview
Enterprise-grade analytics system simulating pricing experiments and A/B testing across customer segments to measure revenue impact and conversion uplift.

## Features
- Large-scale A/B test simulation (20K users)
- Segment-based conversion modeling
- Revenue optimization and uplift analysis
- Statistical significance testing (t-test)
- KPI aggregation layer (SQL-style analytics)
- Customer segmentation insights

## Tech Stack
Python, Pandas, NumPy, SciPy

## System Design
1. Simulated enterprise user event dataset
2. Business logic-based conversion modeling
3. Pricing experiment impact simulation
4. KPI aggregation engine (SQL-like grouping)
5. Statistical hypothesis testing
6. Revenue lift analysis by experiment group

## Outputs
- Conversion rate comparison
- Revenue uplift percentage
- Segment-level performance breakdown
- Statistical significance (p-value)

## Business Use Case
Used for pricing optimization, experiment evaluation, revenue impact measurement, and product decision-making in SaaS and hospitality platforms.
